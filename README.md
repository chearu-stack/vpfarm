# vpfarm — веб-интерфейс

Статический frontend проекта vpfarm.

## Локальный запуск

Откройте `index.html` через локальный статический HTTP-сервер. Адрес API настраивается в `js/config.js`.

## Публикация через GitHub Pages

В настройках репозитория выберите источник публикации `Deploy from a branch`, ветку `main` и каталог `/ (root)`. После сохранения сайт будет доступен по адресу репозитория GitHub Pages.
